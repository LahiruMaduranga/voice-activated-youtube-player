# 🎵 Voice-Activated YouTube Player

A voice-controlled YouTube audio player powered by Google Gemini AI, SpeechRecognition, yt-dlp, and VLC. Search for songs and control audio playback using natural voice commands.

## ✨ Features

- 🎤 Voice command recognition
- 🤖 Google Gemini AI for natural-language understanding and function calling
- 🔎 YouTube song search using yt-dlp
- ▶️ Audio streaming and playback using VLC
- ⏸️ Pause and resume playback
- ⏹️ Stop playback
- ⚡ Playback speed control
- 🎙️ Automatic microphone scanning and selection

## 🛠️ Technologies Used

- Python
- Google Gemini API (`google-genai`)
- SpeechRecognition
- yt-dlp
- VLC Media Player (`python-vlc`)
- python-dotenv

## 📋 Requirements

- Python 3.10 or newer recommended
- VLC Media Player
- Working microphone
- Internet connection
- Google Gemini API key

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/LahiruMaduranga/voice-activated-youtube-player.git
cd voice-activated-youtube-player
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

**Windows**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install google-genai python-vlc yt-dlp python-dotenv SpeechRecognition PyAudio
```

Upgrade yt-dlp if needed:

```bash
pip install -U --pre "yt-dlp[default]"
```

### 4. Install VLC Media Player

Download VLC from the official website:

https://www.videolan.org/vlc/

Ensure VLC's native libraries are accessible to python-vlc.

### 5. Configure the Gemini API Key

Create a `.env` file in the project root directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey).

Add the following to `.gitignore`:

```gitignore
.env
.venv/
__pycache__/
*.py[cod]
```

**Important:** Never commit your API key to GitHub.

## ▶️ Usage

Run your Python script:

```bash
python main.py
```

Replace `main.py` with your actual Python filename.

The application will:

1. Scan available microphones.
2. Ask you to select a microphone.
3. Initialize the Gemini client.
4. Listen for voice commands.
5. Execute the requested audio operation.
6. Return a response generated by Gemini.

**Note:** The current implementation uses `mode = "2"`, so voice input is always selected.

## 🧠 How It Works

1. **Voice Recognition:** SpeechRecognition captures speech through the selected microphone and converts it into text.
2. **AI Processing:** Gemini interprets the user's request and selects an appropriate function.
3. **Function Execution:** Python executes the selected function locally.
4. **YouTube Search:** yt-dlp searches YouTube and extracts an audio stream URL.
5. **Audio Playback:** VLC plays the extracted audio stream and manages playback controls.
6. **AI Response:** The function result is sent back to Gemini to generate a response.

## 🔐 Privacy and Security

- Store API keys in environment variables.
- Keep `.env` out of version control.
- Speech recognition uses Google's online recognition service.
- Gemini requests are sent to Google's API.
- YouTube search and audio extraction require an internet connection.
- Audio playback is handled locally by VLC.

## 🛠️ Troubleshooting

### Microphone Not Detected

Check microphone permissions and ensure the device is connected and enabled.

```bash
pip install SpeechRecognition PyAudio
```

### Gemini API Error

- Verify that `.env` exists in the project root.
- Check that `GEMINI_API_KEY` contains a valid API key.
- Confirm your internet connection and API access.

### VLC Playback Error

- Install VLC Media Player.
- Ensure VLC's native libraries are accessible.
- Verify that the extracted audio stream URL is valid.

### YouTube Extraction Error

Update yt-dlp:

```bash
pip install -U --pre "yt-dlp[default]"
```

### Speech Recognition Error

Check your microphone, internet connection, permissions, and background noise.
